## Ajouter une vidéo de fond
1. Télécharge une vidéo libre de droits (par ex. sur pexels.com/videos ou mixkit.co : « code », « server », « city night »). Prends la version 720p ou 1080p et vise moins de 10 Mo.
2. Mets-la dans `assets/videos/` (par ex. `assets/videos/hero.mp4`).
3. Dans `script.js`, remplis `const HERO_VIDEO = "assets/videos/hero.mp4";`.
